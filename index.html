Detección de errores

Fragmento de código Error 
              
                <title>Ejemplo con errores
Falta la etiqueta de cierre: </title> 
              
                <p>Este párrafo tiene una etiqueta <span style="color: red">
                sin cerrar correctamente.
Faltan las siguientes etiquetas de cierre: </p> y </span> 
              
                <img src="imagenes/logo.png" alt=Logo HTML width="200">
El atributo alt debe recibir una cadena de caracteres, por lo que debería ser: alt="Logo HTML" 
              
                <a href="https://www.google.com" target="blank">Ir a Google</a>
Para que el enlace sea abierto en una nueva pestaña, debe escribirse: target="_blank" 
              
                <ul>
                  <li>Elemento 1
                  <li>Elemento 2
                  <li>Elemento 3
                </ol>
Cada elemento de la lista no posee su etiqueta de cierre: </li>. Además, la etiqueta de cierre correcta para una lista desordenada es: </ul> 
              
                <tr>
                  <th>Nombre</th>
                  <th>Edad</th>
Falta la etiqueta de cierre de la fila: </tr>. Además, al ser la fila del encabezado de la tabla, este fragemento debe estar dentro de las etiquetas <thead> y </thead> 
              
                <tr>
                  <td>Juan</td>
                  <td>30</td>
                </tr>
Al ser una fila de datos de la tabla, debe estar contenida dentro de las etiquetas <tbody> y </tbody>
